# 🚀 VisionBuild AI - Premium Mobile-First AI Software Factory

A high-end, futuristic mobile app showcasing a complete AI software factory experience with dark mode, deep purple surfaces, and glowing cyan interfaces.

## ✨ Features

### 🏭 Factory Hub
- Real-time AI Compute statistics with glowing animations
- Apps Shipped counter with animated progress bars
- Big glowing "Initiate AI Architect" button
- High-fidelity futuristic design

### ⚙️ AI Builder
- Custom image upload with drag-and-drop placeholder
- Application description input
- "Compile Application" button with multi-stage loading sequence
- Tracks compilation stages:
  - 🧠 Logic Mapping
  - 💻 Code Injection
  - 🗄️ Database Provision
  - 🚀 Live Deploy

### ✨ Spark Sandbox
- Split-screen layout (50/50 mobile-optimized)
- **Top Half:** Interactive "Episode Spark AI" story game
  - Choice-based adventure system
  - Dynamic scene navigation
  - Beautiful card-based UI
  - Interactive decision tracking
- **Bottom Half:** Real-time system terminal
  - Simulated deployment logs
  - Green tech aesthetic
  - Live status updates
  - Animated text rendering

### 🎨 Design Excellence
- **Dark Mode:** Gray-950 base with deep purple accents
- **Color Palette:** Cyan glows, purple gradients, green terminal text
- **Animations:** Smooth transitions, pulse effects, glow shadows
- **Mobile-First:** No horizontal scrolling, fully responsive
- **Bottom Navigation:** Three-tab system for seamless navigation

## 🛠️ Tech Stack

- **React 18** - UI framework
- **Tailwind CSS 3** - Styling and animations
- **Vite** - Build tool and dev server
- **PostCSS** - CSS processing

## 📦 Installation

```bash
npm install
```

## 🚀 Development

```bash
npm run dev
```

The app will open at `http://localhost:5173`

## 🏗️ Building

```bash
npm run build
```

## 📱 Mobile Optimization

The app is optimized for mobile devices with:
- Viewport meta tags for proper scaling
- Constrained max-width containers
- No horizontal overflow
- Bottom navigation that doesn't interfere with content
- Touch-friendly button sizes
- Proper spacing and padding

## 🎯 Key Features Details

### Interactive Story System
- Non-linear narrative tree
- 11+ unique scenes
- Dynamic option-based choices
- Stats tracking (episodes, choices made, live status)
- Smooth scene transitions

### Compilation Animation
- 4-stage sequential progression
- Animated progress bars per stage
- Emoji indicators for each phase
- Total animation duration: ~8 seconds
- Completion status message

### Terminal Simulation
- Realistic terminal aesthetics
- Line-by-line text animation
- Green monospace font
- Live deployment status indicators
- Auto-scrolling content

## 🎨 Customization

All colors, animations, and content can be easily customized:
- Edit `tailwind.config.js` for color themes
- Modify component files to change content
- Adjust animation timings in CSS
- Update story tree in `EpisodeSpark.jsx`
